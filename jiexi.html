V3.8 商品ID优先去重

多表格合并时，同一店铺内优先以表格 商品ID / ID 列作为唯一去重键；没有独立ID列时才从链接参数 id=数字 提取商品ID；只要商品ID相同，就视为同一个商品，不再受域名、活动参数、追踪参数或链接形式差异影响。没有商品ID时才使用规范化后的完整链接兜底；既没有商品ID也没有链接时不自动去重，避免误删。文件夹多店铺模式按“店铺 + 商品ID”隔离，不会把不同店铺的数据互相去掉。

商品ID与排序

网页会优先读取表格中的 商品ID / ID 列；没有独立ID列时，再从商品链接参数 id=数字 中自动提取商品ID。按当前商品库规律，ID 数值越大越接近新品，因此商品图册新增“新品 → 旧品 / 旧品 → 新品”排序；商品明细中的商品ID、一级类目、二级类目、三级类目、销量表头都可以点击正反向排序。没有可提取商品ID的特殊链接始终排在最后。

V3.5 导入方式

1. 单表 / 多表导入点击“导入表格”，可一次选择 1 个或多个 XLSX / XLS / CSV，自动合并后分类去重。
2. 文件夹 / 多店铺导入点击“导入文件夹”，递归读取所有表格；根目录下一级子文件夹名自动识别为店铺名。
3. 店铺切换与导出在“店铺视图”切换全部店铺或单店，统计、图册、明细和导出结果全部联动。

推荐表头

最适配：商品信息、图片链接、商品价格、销量、SKU、分期免息、链接。同时完整兼容淘宝商品导出格式：主图链接、ID、标题、商品价格、付款人数、收藏数、店铺、商品链接；其中主图链接作为商品图片、ID 作为商品ID、付款人数作为销量，普通单/多表导入时也会读取“店铺”列。也兼容常见别名，例如商品名称、标题、主图、售价、销售量、商品链接。

分类逻辑 V3.4

V3.4 延续“标题先判定、SKU 后辅助”。先清洗品牌词和营销修饰词，再拆解标题中的核心商品词、功能词、场景词和材质词；SKU 不再参与主评分，避免规格里出现“坐垫、面碗”等词时把主商品带偏。标题规则未命中时先做商品族推断，最后才使用 SKU 作为低置信度辅助。

类目统计快捷跳转

在“类目统计”中点击一级、二级或三级类目标签，可自动同步对应类目筛选并切换到商品图册查看结果。一级标签筛选一级类目，二级标签锁定一级+二级，三级标签锁定完整三级路径。

自动去重

V3.8 改为“商品ID优先、完整链接兜底”。同一店铺内，优先使用“商品ID / ID”列判断重复；无独立ID列时，链接参数 id= 后的商品ID相同即合并，不再要求链接域名或其他参数完全一致；没有商品ID时才按规范化完整链接去重；无ID且无链接的记录不会自动合并。重复记录销量取较高值，并补齐空字段与来源文件。状态栏会分别显示按商品ID合并和按链接兜底合并的数量。

类目筛选与搜索

一级、二级、三级类目继续使用页面内独立滚动菜单，避免滚轮异常跳回顶部。二级和三级类目的下拉菜单顶部新增搜索框，可直接输入类目关键词即时缩小结果，搜索不会改变当前已选类目。

Excel 解析

CSV 可直接在浏览器中解析；XLSX/XLS 会按需加载浏览器版 Excel 解析组件，因此第一次使用 Excel 导入时建议保持联网。商品内容本身只在当前页面内处理。
